## Before 2026-11-04

`wave-makabera-7726187.jpg`: NickelOS's default wallpaper from 2026-10-12
until the Unsplash set replaced it (Dresden's choice). A breaking ocean
wave, photographed by **makabera** on Pixabay:
https://pixabay.com/photos/wave-7726187/ (4200x2800, downloaded 2026-10-04).

License: the Pixabay Content License (https://pixabay.com/service/license-summary/).
Free to use, commercially too, with no attribution required (credit given
here anyway). It is **not** public domain or CC0, and it prohibits selling or
distributing the image "on a Standalone basis", meaning unchanged, as a file
of its own. A default wallpaper shipped unchanged in an OS image arguably is
that. **Before the first public release**, settle it: written permission from
the photographer, or creative changes that make it NickelOS's own, or a CC0
photo instead.

`wave-makabera-7726187-dark.jpg`: dark mode's default wallpaper (2026-10-30,
Dresden's darker grade of the same photo, 2528x1684, framed exactly as the
original). The same photo, so the same license and the same open question
above.

`nickel-light.svg`, `nickel-dark.svg`: the brush-stroke wallpapers
(make-wallpaper.py, ../stroke/brush.py), NickelOS's own; the default from
2026-10-12 until the wave replaced it the same day. The website's hero streak
is the same stroke.
